# Animation demos

The registry contains five allowlisted React components. Vite loads both each component and its exact TSX source lazily. Copying a source file gives a complete default-exported component with imports and inline styling; no private helper imports or application CSS are required. Use it in a React + TypeScript app with `gsap` and `@gsap/react`; the cube also requires `three` and `@react-three/fiber`.

Render the selected registry component inside React Suspense. Demos use the window's ordinary vertical scroll; do not place them inside a transformed or independently scrolling ancestor. Pin-scrub holds its stage for two viewport heights. Depth-parallax moves three layers by 100, 260, and 480 pixels across the same scroll interval. Scroll-cube maps the scroll range of its 240svh track to two mesh rotation axes. Svg-draw animates the `strokeDashoffset` of an SVG path from `getTotalLength()` to `0` across its stage scroll interval. Svg-morph interpolates the `d` attribute of an SVG path from a four-segment cubic Bézier circle to a four-pointed star across its stage scroll interval.

Reduced motion is reactive. GSAP matchMedia reverts the DOM and SVG demos, removing the pin spacer, transforms, dashoffset, and path morphing so the complete static illustration and shape comparison remain visible in normal flow. The cube unmounts WebGL and displays an SVG illustration in normal flow. Renderer creation errors and context loss also produce that fallback. Cube resources are component-owned declarative R3F geometry/materials, disposed when unmounted. Demand rendering, capped DPR, visibility gating, and no continuous useFrame loop limit idle work. These are implementation choices, not a measured 60 fps guarantee.

Browser verification should cover forward/reverse scrolling, changing reduced motion while mounted, resizing, Strict Mode remounts, navigation away/back, disabled WebGL, and context loss. Stable selectors are `pin-stage`, `pin-square`, `parallax-back`, `parallax-middle`, `parallax-front`, `cube-track`, `cube-stage`, `cube-fallback`, `demo-svg-draw`, `svg-draw-stage`, `svg-draw-path`, `demo-svg-morph`, `svg-morph-stage`, and `svg-morph-path` through `data-testid`.
